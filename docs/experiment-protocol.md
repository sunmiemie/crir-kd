# 实验协议草案

## 研究状态与可检验问题

本文件是未来实验的预先约定，不代表实验已经完成。核心问题：固定学生结构及测试输入尺寸后，实例可靠性加权能否提高微小目标检测，并提供超过简单质量加权的收益？

## 数据和划分

- 教师和学生只使用约定训练集进行训练；验证集用于开发和选参；测试集用于最终评价。
- VisDrone 必须使用 DET 图像任务，不混用 VID/MOT 的视频划分；按官方规则处理忽略区域。
- AI-TOD 与 AI-TOD-v2 不混用标注。记录具体下载版本、划分文件和评测代码版本。
- 官方尺度分组用于主表；学生输入中的像素尺度只用于额外诊断，两种定义分别标明。
- 若发现标注疑点，先记录核查。修改训练标注应披露额外标注工作；不通过自行改变测试标注与既有结果直接比较。
- 数据与权重不提交到 Git；使用官方资源并遵守各自使用条件。

## 固定变量

比较加权策略时，固定学生结构、输入尺寸、教师检查点、蒸馏特征层、通道投影、训练轮数、优化器、增强和基础 KD 损失。

所有方案都保留完整 GT 检测监督。控制平均 KD 强度，或增加全局损失权重调参对照，区分“更好地选择实例”和“仅减少了 KD 总量”。

## 基线与消融

| 设置 | 用途 |
| --- | --- |
| 学生无 KD | 基础检测能力 |
| 同分辨率普通 KD | 区分一般蒸馏收益和分辨率因素 |
| 跨分辨率普通 KD | 高分辨率教师本身的收益 |
| 置信度加权 | 简单教师评分基线 |
| 尺寸加权 | 排除仅偏重某个尺寸组的收益 |
| GT 质量 q-only | 全监督下可实现的强基线，不是不可实现的 oracle |
| 稳定性 s-only | 稳定性本身的作用与风险 |
| q 与 s 联合 | 检查稳定性的额外价值 |
| 相同额外前向次数的多视图平均质量 | 排除额外教师计算带来的混淆 |
| 尺寸与质量分组内打乱权重（后续） | 检查正确实例排序是否重要 |

方法复现或 YOLO 适配必须记录改动，不能将不同结构、训练预算和评测协议下的数字直接解释成算法优势。

## 关键诊断

1. 教师优势是否存在于最小目标组，而不仅是总 AP。
2. 控制目标尺寸、GT 质量后，稳定性是否还提供可重复的信息。
3. 统计每个尺度组的匹配缺失率、平均权重、学生 AP 与召回率。
4. 扰动结果必须逆变换到相同坐标；框对应允许无匹配，避免密集目标之间串配。
5. 记录所有目标的教师漏检，不能只分析多视图均成功检出的目标。
6. 缓存可靠性与当前几何增强要一致；Mosaic、裁剪、改变视野会影响缓存适用性。
7. 可比较 T(I_H) 与 T(U(D(I_H))) 诊断降采样信息损失，固定重采样方法；后者不等同于低分辨率学生。

## 报告指标

- 主指标：官方检测 AP，整体与官方 tiny/small 分组结果。
- 补充指标：AP50、AP75、召回和误检分析，按数据集定义说明。
- 推理成本：参数量、计算量、端到端延迟、设备、输入尺寸、精度模式、batch size、预热与测量方式。
- 训练成本：训练时间、峰值显存、教师额外前向次数、配置与种子。
- 核心结果使用多个随机种子并报告离散程度；未重复的结果明确标记单次运行。
- 不填写预期数字冒充实测结果，示意数据必须单独标记且不进入主结果表。

## 每次运行的最小记录

记录实验 ID、代码 commit、配置文件、环境版本、数据版本及划分、模型权重来源、输入尺寸、训练设置、种子、日志位置、评测命令及原始结果。

## 停止或调整的条件

- 教师没有微小目标优势：先改善教师或调整数据/分辨率条件。
- 普通 KD 不稳定：先核查几何对应、特征层和损失强度。
- 联合评分不优于调好的 q-only：稳定性设计尚无独立证据。
- 总体提升依赖牺牲最小目标组：不支持当前主要研究主张。
- 结果依赖测试集调参、单个种子或额外训练预算：补足公平性与重复性证据后再形成结论。
