# 研究计划：跨分辨率实例可靠性引导知识蒸馏

**状态：研究方案草案。当前仓库尚未实现完整训练流程，也没有实验成绩。**
本文规定要验证的问题和实验边界，不能据此声称方法有效或具有已确认的创新性。
计划使用公开数据集，在 3–6 个月内形成可复现的实验和论文初稿；不保证录用结果。

## 1. 研究问题

微小目标在低分辨率输入中只占少量像素，容易漏检、误检和定位偏移。
高分辨率教师可能保留更多目标信息，但指导并非对每个目标都可靠。
研究问题是：在固定学生结构及测试输入尺寸时，按实例选择教师指导能否改善检测？
这里的实例指一辆具体的汽车或一个具体的行人，而不是整张图片。
核心假设是：预测稳定性可能提供超出教师置信度与 GT 匹配质量的有效信息。
该假设有可能不成立，必须通过受控实验判断。

## 2. 预期使用方式

- 训练：同一原图产生高分辨率教师视图与低分辨率学生视图。
- 训练：学生接受完整 GT 监督，并参考教师的目标局部特征。
- 部署：仅保留学生检测器，输入新图片后输出目标框、类别和分数。
- 目标：提高微小目标检测能力，同时保持学生部署结构与输入尺寸不变。
- 边界：不能恢复输入中完全消失的信息，不保证学生超过教师。

## 3. 第一版模型范围

先选择同一 YOLO 家族，学生使用已能稳定训练的轻量配置。
教师需在所研究的微小目标组上表现更好，不能只检查整体 mAP。
教师可采用更高输入分辨率；是否采用更大网络由算力和基线实验决定。
蒸馏阶段冻结教师参数，关闭教师参数梯度，并使用适当的评估模式。
学生保留原有检测头与完整检测损失，不把教师预测当作新的 GT。
第一版只对一个已有的较高空间分辨率特征层进行局部特征蒸馏。
不同时添加新主干、超分辨率、多个注意力模块或新的检测头。

## 4. 局部特征如何对应

以 GT 框确定同一个实例在师生视图中的区域，可适度包含周围上下文。
坐标转换必须覆盖缩放、补边、翻转、裁剪和特征层步长。
把两边目标区域采样为相同空间尺寸，再比较其特征。
可使用 RoIAlign 建立区域对应；它是实现工具，不作为独立创新。
通道不同可在学生侧加入仅训练使用的投影层，推理时移除。
特征采样放大不会产生新信息，应记录目标在学生特征层上的实际尺度。
首个原型先关闭复杂几何增强，确认对齐正确后再逐项恢复并公平比较。

## 5. 实例质量 q 与稳定性 s

质量 q 衡量教师当前预测与已有 GT 的匹配程度。
初始方案可结合真实类别分数与预测框相对 GT 的 IoU。
匹配规则、匹配阈值和未匹配处理必须明确，不能强行匹配附近其他目标。
稳定性 s 衡量教师在少量轻微几何扰动下，对同一实例的预测一致程度。
每次预测先逆变换到共同原图坐标系，再比较中心位置和宽高变化。
扰动视图仍通过 GT 对应实例，记录目标在各视图中的可见性和有效匹配数。
框变化按目标大小归一化，并设置数值下限以避免极小框导致异常。
可尝试 `s = (有效匹配数 / 有效视图数) × exp(-归一化变化 / τ)`。
因裁剪而不可见的视图应排除，不能直接视为教师漏检。
教师稳定地预测错误仍然不可靠，因此不能只看 s。
q 与 s 由冻结教师和 GT 计算，作为不参与反向传播的训练权重。

## 6. 最小损失方案

可以从 `L = L_YOLO + λ × mean(w_i × L_KD_i)` 开始。
`L_YOLO` 保持对所有有效 GT 的正常监督。
`L_KD_i` 比较第 i 个实例对齐后的师生局部特征。
`w_i = ε + (1 - ε) × q_i × s_i` 是候选形式，不是确定的最终算法。
局部特征来自 GT 区域，因此教师漏检时仍可提取，但是否保留蒸馏须验证。
对权重下限 ε、归一化方式与全局强度 λ 做明确记录。
不同策略应控制平均蒸馏强度，防止收益仅来自整体减弱 KD。
也应允许所有教师指导都不可靠的批次降低整体影响，并做对应控制。

## 7. 微小目标保护与跨分辨率诊断

困难微小目标容易获得低权重，不能让方法退化为只学习容易目标。
始终保留这些目标的 GT 监督，统计各尺寸组的平均权重和权重分布。
检查最小目标组的教师漏检率、学生召回率、误检和定位误差。
比较有无权重下限，以及按尺寸分组校准权重的必要性。
用教师原图输入与“先降采样再放回原尺寸”的输入做信息损失诊断。
放大后的图像不能称为细节恢复结果；它只用于观察降采样敏感性。
不要预设降采样敏感目标必然应该少蒸馏，应先检验实际收益关系。

## 8. 必须具备的对照

| 对照 | 要排除的解释 |
| --- | --- |
| 无蒸馏学生 | 训练方案是否优于普通训练 |
| 普通局部特征蒸馏 | 是否仅加入 KD 就足够 |
| 教师置信度加权 | 是否只需最简单的评分 |
| GT 质量 q-only 加权 | 稳定性是否超出已知质量信息 |
| 稳定性 s-only 加权 | 稳定性单独是否有效 |
| q 与 s 联合加权 | 联合信息是否有额外收益 |
| 多视图平均质量加权 | 收益是否仅来自额外教师前向 |
| 匹配平均权重和 λ 的对照 | 收益是否仅来自减少蒸馏总强度 |
| 相同分辨率与不同分辨率比例 | 问题是否与分辨率差距有关 |

q-only 是全监督训练下可直接使用的强基线，不能省略。
进一步可在相同尺寸和质量组内打乱权重，检验实例排序是否真正有效。
核心方法成立后，再进行第二个师生组合与第二数据集验证。
复现相近方法时记录代码版本、适配内容、配置及训练预算。

## 9. 数据划分与报告规范

以 VisDrone-DET 开始调试，在 AI-TOD-v2 上补充微小目标验证。
保持训练、验证和测试划分固定，遵循数据集许可与官方评价规则。
教师与学生只能使用允许的训练数据，验证集用于开发，最终测试不参与调参。
同源视频帧存在时，检查划分方式，避免近重复画面跨集合造成泄漏。
区分官方尺寸分组与目标在学生输入中的像素大小，并分别报告。
记录 mAP、官方尺度指标、微小目标召回率、端到端延迟与峰值显存。
同时报告训练时间、额外教师前向次数和扰动视图数量。
关键基线与最终方法使用多个随机种子，并报告均值及波动。
教师稳定性缓存只有在输入变换与上下文一致时才可复用。

## 10. 阶段计划和停止条件

| 阶段 | 工作与判断依据 |
| --- | --- |
| 第 1–2 周 | 跑通基线，确认教师在微小目标上有优势，检查坐标与质量统计 |
| 第 3–5 周 | 实现普通局部特征 KD，比较 q-only、s-only 与联合加权 |
| 第 6–10 周 | 完整训练、同算力多视图对照、关键消融与第二数据集 |
| 第 11–16 周 | 多种子验证、相关方法比较、失败案例分析和论文初稿 |
| 后续预留 | 处理复现差异、补充实验、修改稿件与投稿 |

教师对微小目标没有优势时，先修复教师或收缩目标，不直接推进复杂 KD。
普通 KD 无稳定收益时，先检查对齐、损失强度和分辨率差距。
联合加权不优于充分调好的 q-only 时，不声称稳定性机制有效。
总 mAP 提升但最小目标组明显退化时，不声称解决了微小目标问题。
收益随公平算力或多种子对照消失时，应调整方案并如实报告。

## 11. 已知相关工作与数据入口

- [CRKD-YOLO](https://github.com/Jianfantasy/CRKD-YOLO)：跨分辨率 YOLO 蒸馏相关工作。
- [MSAD，CVPR 2021](https://openaccess.thecvf.com/content/CVPR2021/html/Qi_Multi-Scale_Aligned_Distillation_for_Low-Resolution_Detection_CVPR_2021_paper.html)：低分辨率检测的多尺度对齐蒸馏。
- [Soft Teacher，ICCV 2021](https://openaccess.thecvf.com/content/ICCV2021/html/Xu_End-to-End_Semi-Supervised_Object_Detection_With_Soft_Teacher_ICCV_2021_paper.html)：半监督检测中利用框扰动评估定位可靠性。
- [AvatarKD](https://arxiv.org/abs/2305.02722)：教师相关不确定性与蒸馏的相关研究。
- [CrossKD](https://github.com/jbwang1997/CrossKD)：检测蒸馏及监督冲突相关工作。
- [VisDrone](https://github.com/VisDrone/VisDrone-Dataset)；[AI-TOD-v2](https://chasel-tsui.github.io/AI-TOD-v2/)：公开数据及使用入口。

上述研究说明若干组成概念已有先例；最终创新性仍需在定稿前进一步查重。
